# 使用说明

## 设置

界面汉化、思维链汉化和自定义窗口尺寸默认关闭，分别在 Hub 设置页开启。界面汉化保留插件、技能、规则与聊天正文的原文。需要重启的改动会在退出设置页时提醒。

首次启动默认进入托盘，关闭窗口也默认最小化到托盘；这些选项可在设置中调整。窗口初始尺寸为 1400×900 逻辑像素，未开启自定义尺寸时沿用客户端行为。

## 翻译与会话速率

固定界面文字使用本地词典，部分动态提示和用户开启的思维链汉化使用腾讯／有道翻译。思维链汉化会发送客户端已经展示的思考片段。

状态栏速率是当前会话已完成请求的加权平均值：有效正文输出 token 总量 ÷ 对应流式生成总时长，不计首 token 等待和工具执行时间。约每 3 秒刷新，无有效记录时显示 `—`，不上传会话内容。

## OAuth 本地配置

首次使用建议选择「识别客户端」，导入 Antigravity 中已经登录的账号。没有本地 OAuth 配置时，直接 Google 授权不可用，界面会提示改用客户端导入。

公开源码不包含 OAuth 客户端 ID / secret。本机试用沿用已有配置，配置存入用户目录的 DPAPI 加密 `oauth_client.dat`，不进入项目目录或发布包。Google 授权、访问令牌刷新等路径需要与你的客户端 / 服务相匹配的 OAuth 配置。不能假定任意新建 Google OAuth 客户端都能访问 Antigravity 内部接口。

在自己的 Windows 用户环境中设置 `ANTIGRAVITY_OAUTH_CLIENT_ID` 和 `ANTIGRAVITY_OAUTH_CLIENT_SECRET` 后，重新打开 Hub。值只保存在本机环境中，不应写入源代码或提交 Git。

没有配置时仍可查看本地用量；读取已有、有效的客户端令牌不依赖新建授权。需要刷新或新授权时会报告配置缺失。账号切换、订阅和配额仍受客户端接口与权限影响。

## 本地数据

账号、加密令牌、用量和设置保存在 `%USERPROFILE%\.antigravity_hub`。用量金额仅作参考估值。

## 客户端兼容性

客户端增强仅适配 Antigravity 2.22.0 Windows x64。Hub 自动准备组件，并等待客户端正常退出后应用；未知版本不会被修改。已经打过旧补丁的客户端可能需要提供同版本原版包，见 [开发与维护](DEVELOPMENT.md#客户端补丁与原版底包)。回退步骤见 [客户端增强说明](CLIENT_ENHANCEMENTS.md#安装与回退)。

## Hub 更新

设置中的「Hub 更新」显示当前版本、检查结果及可用更新。「启动时检查更新」默认开启；检查失败不会阻止使用，稍后可手动重试。

更新只读取 `Cainite07/AntigravityHub` 的 GitHub 正式 Release，不跟踪代码提交、草稿或预发布版本。点击「更新并重启」后，Hub 下载完整 Windows x64 包并校验 SHA-256、版本与逐文件清单；下载失败或校验失败时继续运行当前版本。

下载完成后，更新助手等 Hub 正常退出，备份并替换发布包拥有的文件，重启同一路径的 Hub。新版界面与本地数据初始化成功后清除系统临时目录中的下载包、助手和备份。账号、设置及用量仍留在原来的用户目录；客户端缓存底包和用户另外放入的文件不纳入更新清理。

替换失败或新版无法启动时会尝试恢复旧版并打开 Hub。异常断电后，下次启动会先尝试恢复未完成的更新。如果目录权限、杀毒拦截或磁盘错误使恢复无法完成，备份会保留，不会提前删除；可重新解压完整发布包到原目录恢复程序，本地账号数据不会随程序替换丢失。

旧版用户需先安装一次 1.4.0，后续才有内置更新入口。
