# AntigravityHub 1.4.0

本版发布包已修订：修复 Google 授权启动失败时一直停留在等待页面的问题。缺少本地授权配置时，会返回初始页面并提示使用「识别客户端」导入已登录账号。旧的 1.4.0 安装包需重新下载，版本号不变。

同时修复设置页重启 Antigravity 时仅关闭窗口、客户端停留在托盘且 Hub 等待超时的问题。现在通过客户端正常退出流程应用设置，再打开窗口；窗口出现后才结束等待。保留退出确认，取消退出时不会强制结束客户端。

- 新增内置更新：默认每次启动检查 GitHub 正式 Release，设置中可手动检查或关闭启动检查。
- 发现新版本后提示，托盘运行时也会通知；用户点击「更新并重启」后才下载和安装。
- 更新包先验证完整 SHA-256 和逐文件清单，再退出 Hub、原位覆盖并重启。
- 自动删除旧版程序清单中已移除的文件；保留账号、设置、本地用量和客户端原版底包缓存。
- 新版界面与数据初始化成功后清理下载包、临时目录和回退备份。文件替换失败或新版启动失败时恢复原版本；意外中断的替换会在下次启动尝试恢复。

更新只重启 Hub，不会结束 Antigravity。客户端增强仍适配 Antigravity 2.22.0 Windows x64；新客户端版本需要单独完成适配并发布新 Hub。

旧版未包含更新入口，请先安装一次 1.4.0。此后从 Hub 更新，无需再次手动下载。
