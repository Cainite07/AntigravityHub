# AntigravityHub 2.25.2

- 增加小型适配包更新：主程序和运行环境一致时，只下载完整的最新适配层，可跳过中间适配版本。更新前显示包类型和大小，仍支持覆盖、重启及失败恢复。
- 首次从 2.25.1 或更早版本升级，需要下载一次完整包来获得新更新器。以后仅调整汉化、客户端补丁或状态栏组件时，可以发布小包；主程序或依赖变化时仍使用完整包。
- 小包失败不会自动消耗流量下载完整包，会显示原因和完整包大小，由用户再次点击决定。
- 发布流程加入汉化漏项检查，检查已知词条未应用、补丁清单不一致，以及新发现的英文候选。插件介绍、动态任务文字与不确定内容留待人工判断，不自动翻译。
- 同步补齐旧版 2.23.0 的时间与工具操作状态文字。客户端兼容范围保持 2.22.0、2.23.0、2.23.1、2.24.0、2.25.0。
- 保留账号、设置、OAuth、用量历史和客户端缓存底包；不增加后台启动设置。
