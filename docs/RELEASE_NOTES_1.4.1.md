# AntigravityHub 1.4.1

精简发布包，保留 1.4.0 的全部功能与修复。

- 合并并压缩 .NET 运行库，减少程序目录中的散落文件。
- 去除维护依赖中的类型声明、源码映射和开发命令入口，保留运行脚本与许可证。
- 演示图和开发文档保留在 GitHub 与源码包；Windows 包保留使用说明和客户端增强说明。
- 继续自带 .NET、Node.js 和 Python，解压即可使用，不额外下载运行组件，也不在启动时解压运行库。

1.4.0 用户可通过 Hub 内置更新升级，保留账号、设置与本地授权配置。客户端增强继续适配 Antigravity 2.22.0 Windows x64。

修复 Google 授权等待与客户端重启问题的版本仍为 [1.4.0](RELEASE_NOTES_1.4.0.md)，精简打包从本版开始。
