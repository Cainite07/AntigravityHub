# AntigravityHub 1.3.3

Windows 上的 Antigravity 账号、用量与客户端增强工具。客户端增强适配 Antigravity 2.22.0 Windows x64。

## 本版功能

- 精简状态栏：头像、5 小时剩余额度圆环、会话平均输出速率、今日 token 用量。
- 账号面板：两组 5 小时额度圆环、每周额度条、备用账号切换；采用 85% 比例和提高的字号，无阴影，跟随客户端配色。
- 界面汉化和思维链汉化分开控制，均默认关闭。
- 补充自定义配置分类、空状态、自动化创建、模型提示、历史消息控件和归档提示的汉化；插件、技能、规则和聊天正文保留原文。
- 可调整客户端窗口尺寸；未启用时沿用客户端原有行为。
- 修改需要重启的设置后，退出设置页会显示重启提醒与快捷按钮。
- 完整 Windows 发布包内置所需运行组件，不需要手动安装客户端增强。

## 使用

下载 Windows x64 压缩包并完整解压，打开 `AntigravityHub.exe`。首次启动默认进入托盘，按 **Alt + A** 或再次打开程序显示窗口。

会话速率是有效正文输出 token 总量除以流式生成总时长，排除首 token 等待与工具时间；它显示当前会话已完成请求的加权平均值。无有效记录时显示 `—`。

## 数据与兼容性

发布包不包含个人账号、令牌、真实用量、运行日志、Antigravity 原版程序或客户端底包。用户数据保存在自己的 Windows 用户目录中。固定界面翻译使用本地词典，部分客户端动态公告和用户开启的思维链汉化使用翻译服务。

客户端增强会核验已支持的版本和文件。客户端升级后若不兼容，维护器拒绝修改；客户端运行期间等待它正常退出后应用组件，不会强制结束任务。

需要授权登录或刷新令牌时，请先阅读 README 的「OAuth 本地配置」。未配置可用 OAuth 客户端时，这些路径不可用；本地用量查看仍可使用。
