# AntigravityHub 2.29.0

适配 Antigravity 桌面版 2.29.0。首次使用请下载 `AntigravityHub-2.29.0-Windows-x64.zip`，完整解压后运行 `AntigravityHub.exe`。从上一公开版 2.25.2 升级，可直接在 Hub 内检查更新。此次包含主程序更新，更新器会自动选择完整包。

- 新对话首页根据有无称呼显示中文问候，保留用户姓名。
- 自动化任务的空列表、创建表单、搜索提示、重复周期、星期和时间均已汉化。任务名称、工作区名称和实际排期保留原值。
- 更新外观、快捷键、内置浏览器、语音和模型用量设置的中文说明。可照打的命令和按键保持原有拼写，例如 `/plan` 和 `Shift`。
- 独立汉化层同步了 2.29.0 的已审核译文。后续客户端更新时，仍能识别的控件可以继续显示中文。聊天正文、代码、语音转写和网页内容保留原文。
- 适配新版窗口恢复逻辑，以及客户端状态栏在主窗口中的显示。

发布页中的 `Adaptation.zip` 供内置更新器在主程序匹配时使用。需要手动安装或升级时，请选 Windows x64 完整包。
