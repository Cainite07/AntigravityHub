# AntigravityHub 2.23.1

增加用量历史的独立备份与自动恢复保护，继续适配 Antigravity 2.23.0。

- 用量记录保存完整 SQLite 日备份，位于“文档 / AntigravityHub / 历史备份”，保留最近七天，独立于程序目录和用户数据目录。
- 数据库丢失时从通过完整性检查的备份恢复；重建后缺少历史记录时按来源与编号合并，保留现有记录和扫描进度，避免重复计数。
- 通过记录身份检查缺失，避免新旧记录数量相同而漏过；损坏的最新备份会回退到较早的有效备份。
- 备份只包含模型、时间与用量记录，不包含账号凭据或对话正文。

正常程序更新保留用户数据。清理程序本体时，请保留 `.antigravity_hub` 和上述历史备份目录。
